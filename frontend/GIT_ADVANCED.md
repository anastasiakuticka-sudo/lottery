\# Git Advanced



\## Project

Lottery decentralized application built with React, Solidity, Truffle, Ganache and MetaMask.



\## Git workflow

\- main - stable project branch

\- feature/git-advanced - branch for Git Advanced tasks

\- Changes are committed separately and pushed to GitHub.

\- Pull Requests are used to merge feature branches into main.



\## Hosting

The React frontend is deployed using Firebase Hosting.
